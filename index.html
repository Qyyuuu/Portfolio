Tentang saya

Latar belakang akademik, fokus teknis, dan aktivitas berbagi ilmu.

Saya mahasiswa S1 Informatika di Universitas Singaperbangsa Karawang (UNSIKA) yang berfokus pada pengembangan antarmuka web dan perancangan basis data relasional.

Dalam pengerjaan proyek kuliah maupun tim, saya terbiasa mengikuti alur Software Development Life Cycle (SDLC) mulai dari pemetaan kebutuhan, perancangan skema ERD dan normalisasi MySQL, implementasi modul CRUD berbasis PHP dan JavaScript, hingga penyusunan antarmuka front-end responsif dengan HTML5, Tailwind CSS, dan Bootstrap.

Selain membangun aplikasi web, saya aktif mengajar mata kuliah Basis Data pada program Study Club HIMTIKA UNSIKA serta mengoordinasikan berbagai program pengembangan akademik mahasiswa Informatika.
